Added a no-LLM null baseline for the equation search:
- `edgar_study.symbolic`: expression trees over the stimulus angle whose parameter leaves are fitted per neuron, turned into the same NumPy program, JAX program and parameter estimator an LLM writes. It has random trees, mutation, crossover, the two upstream seeds as trees, and a parser for PySR-style formulas.
- `edgar null-search --seed N`: runs upstream's unchanged search loop (seeds, islands, selection, migration, `lm-bounded` fitting, final databases) with GP proposals in place of the three LLM stages, and writes the same run folder an LLM run does, so `edgar rescore`, `edgar report` and the paper analysis read it.
- `edgar_study.null_test` and `scripts/null_compare/run.py`: refit each run's winner and the double Gaussian on the locked-test cells, take every neuron's held-out loss, and run a paired bootstrap for every LLM winner against every no-LLM winner. The null hypothesis is rejected for a pairing when the 95% interval of the score difference lies below zero.
- `edgar report` reads runs that made no LLM calls (no `api_calls.jsonl`).
- PySR reference arm (`scripts/null_pysr/run.py`, optional `sr` dependency group, so the gate and tests never need Julia): a PySR template search for one formula with per-neuron parameters on 100 discovery cells' fit-half trials. Its Pareto front is converted by `symbolic.from_pysr`, scored with our objective on all discovery cells and written as a run folder for `edgar rescore`.
