Add `--temperature T` to `edgar frontier` for guided scheduling. The scheduler, never the model, weights parents and revisits by exp(−(score − lowest)/T) on exploration scores, shifts new-idea modes towards combinations (single 50%, detour 15%, combination 30%, root 5%), and makes each idea's reference its best-scoring equation. Parent-fit caches are keyed by the reference equation so a new reference is refitted. Without `--temperature`, draws are score-blind and unchanged, so seeded runs reproduce as before.
