Early pipelined fits now wait until no model request is queued, each logged request records how long the event loop was blocked during it (`blocked_s`), discarded early fits are logged, and programs upstream never fits are dropped. METHOD_DIFFS.md now lists the pipelined stage ordering and the 16-request limit, and the timing doc corrects its overlap claim. The fit-floor script skips failed starts, compares both fits over the same cells and rejects unknown curve names; multi-start logs capped fits, and `BoundedFit.converged` is renamed `stopped` because it also counts damping-saturated cells.
