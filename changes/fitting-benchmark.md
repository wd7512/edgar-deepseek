Add `edgar fitbench`, a fitting benchmark that needs no ground truth. `frontier/nested.json` holds 16 equations from the frontier runs, linked by 20 nestings, and every nesting map is checked against its parent's predictions when the file is loaded. A child that fits a neuron worse than its parent is a violation. Each fitter's regret is measured against the best error any saved fitter, or any ancestor, has reached. Fitters see training trials only. The protocol's training fit is now its own function, `fit_equation_training`, which also takes a relative step cap. The discovery split is shared through `datasets.discovery_partition`.
