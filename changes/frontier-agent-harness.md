Each frontier batch is now a short conversation bounded by `--patience` follow-up turns (default 3), replacing the single retry. HY4 can check equations before answering by replying `{"check": [...]}`. It then gets a score-free validity report: syntax, repeats, values undefined or overflowing at the start, and whether each nesting map reproduces its parent, with a working map offered if not. Every submitted equation that cannot be used, including ones that fail to fit, is reported back by position and replaced until patience runs out. Prompts now require a single expression (no assignments or statements) and a nesting map covering every parameter. The client sends the whole conversation each turn. Episodes record `turns` and how the batch `ended`; the checkpoint version is 4.
